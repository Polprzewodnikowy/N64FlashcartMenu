## 64DD Disk support

Specific flashcarts (such as the [SummerCart64](https://summercart64.dev)) can fully emulate the original 64DD (load, run, save) disks without having a physical device connected to the N64 and don't require conversion ROMs.

To load and run 64DD disk images, place the required 64DD IPL dumps in the `/menu/64ddipl` folder on the SD card.
For more details, follow [this guide on the 64dd.org website](https://64dd.org/tutorial_sc64.html).

> [!TIP]
> Expansion disks expect the same region as the ROM image (Japan -> Japan | US -> US).

> [!IMPORTANT]
> Menu-driven swap setup is currently intended for SummerCart64.

### Conversion ROMs
The N64Flashcart Menu is able to load and run conversion ROMs (but does not perform saves).

### Swap disks
The menu can prepare disk swap mappings automatically for supported flashcarts.

How to use:
1. Put the primary and swap `.ndd` files in the same folder.
2. Open the primary disk in the menu and press `A` (or `L`/`Z` when using a ROM+disk combo).
3. The menu scans sibling disks, validates compatibility and maps the allowed set.
4. In-game, perform the disk change using the flashcart swap control when prompted.

Behavior notes:
- The menu enforces compatibility checks and only maps valid swap candidates.
- The number of swap disks is limited by active flashcart capability.
- For best compatibility, return to the primary disk between swaps (for example: 1, 2, 1, 3, 1, 4).

For correct swapping, ensure that you switch them in a compatible context:
Disk Swap Compatibility:
- From DMPJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DMTJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DMGJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DMBJ: DMPJ, DMTJ, DMGJ, DMBJ, EFZJ
- From DKKJ: itself, and DKDJ (required)
- From DSCJ: DMPJ

It is preferable that disks are switched back to the primary disk between each swap, for example: 1, 2, 1, 3, 1, 4...

### Expansion disks
N64 and 64DD Compatible Combo Matches:
- Mario Party 1:           CLBx -> ELBx
- F-Zero X:                CFZx -> EFZx
- Zelda OoT:               CZLx -> EZLx
- Pokémon Stadium 1 (JPN): CPSJ -> xPSJ (E to Z)
- Pokémon Stadium 2 (JPN): CP2J -> xP2J (E to Z)
- Dezaemon 3D:             CDZx -> EDZx & DEZA (Prototype)
  
(Could just be handled with Cxxx corresponding to Exxx aside from Dezaemon 3D that I think the exception is worth doing)
